How to Organize Screenshots: Names, Folders, Tags

Organize screenshots so you can find them again: file naming conventions, automatic name templates, folders, tags, collections and a weekly clean-up.

Shahriar AhmedDeveloper of FrameShotNovember 16, 20268 min read
FrameShot Studio

To organize screenshots, give every file a consistent name that starts with the date, save them into a few predictable folders instead of the desktop, tag or group the ones you’ll need again, and delete the rest once a week. Automatic file names and a searchable library do most of the work, so the routine takes minutes rather than an afternoon.

This guide covers naming conventions, automatic file name templates, download folders, organizing inside FrameShot’s library, finding duplicates, a simple weekly routine, and how to keep private screenshots private.

How should you name screenshots?

A good file name tells you what a screenshot is without opening it, and sorts in a useful order. Default names like “Screenshot 2026-11-16 at 14.05.33” sort by time but say nothing about the content. A simple convention fixes that:

  • Start with the date as year-month-day, for example 2026-11-16. Files then sort in date order in every file manager, and you can find “last March” at a glance.
  • Add where it came from: the website, app or project, such as github.com or acme-redesign.
  • Add what it shows in two or three words: checkout-total-bug, invoice-october.
  • Use hyphens instead of spaces, and avoid characters like / \ : * ? " < > |, which aren’t allowed in file names on some systems.
  • Keep it short. Very long names get cut off in file lists and in chat previews.

Put together: 2026-11-16-github.com-checkout-total-bug.png. You won’t name every capture by hand, which is where templates come in.

Automatic file names with FrameShot templates

FrameShot names downloads from a template you set once in Settings → Export & downloads → File name template. The default is frameshot-{domain}-{date}-{time}, and a live preview under the field shows what a file name will look like. Click a token button to add it to the template.

TokenBecomes
{date}The capture date, as YYYY-MM-DD
{time}The capture time, as HH-MM-SS
{domain}The website, such as example.com (without “www.”)
{title}The page title
{name}The capture’s name in the library, including any name you gave it
{mode}How it was captured, such as full, visible, area or element; recording for videos
{width}, {height}The image size in pixels
{timestamp}The exact capture moment as one long number, useful when you capture many in a row

The template also understands {yyyy}, {mm}, {dd}, {hh}, {min} and {ss} for the individual parts of the date and time. A few useful templates:

  • {date}-{domain}-{title} for research and receipts, sorted by date and labelled by site.
  • {domain}-{date}-{time} when you mostly look things up by website.
  • {date}-{name} if you rename captures in the library before downloading.

A few details that help: the date and time are when you captured the screenshot, not when you download it. Characters that aren’t allowed in file names are replaced automatically, and empty tokens don’t leave double hyphens behind. Recordings use the same template, with their video extension.

Where should screenshots be saved?

Screenshots pile up wherever they land by default, and every tool has a different default:

  • Windows saves Win+PrtScn screenshots in Pictures → Screenshots, and Snipping Tool can save there automatically too. See how to screenshot on Windows.
  • Mac saves screenshots to the desktop. Press Cmd+Shift+5, click Options and pick another folder under Save to. See how to screenshot on a Mac.
  • Chrome saves downloads to the folder set in Settings → Downloads, usually Downloads.

In FrameShot, set Save into a folder inside Downloads in the same settings section, for example FrameShot, so captures don’t mix with every other download. You can use a nested folder such as FrameShot/Receipts, and switch it when you start a project. If you’d rather decide each time, turn on Ask where to save each file.

Keep the folder structure shallow: one folder for screenshots, with a handful of sub-folders by project or purpose, is easier to keep up than a deep tree you’ll stop maintaining after a week.

How to organize screenshots in the FrameShot library

Every capture and recording you make with FrameShot is kept in its library, in your browser, before you download anything. That’s where most of the organizing happens:

  • Search. Press / and type. Search looks through names, page titles, websites, addresses and tags, and typing “recording” finds videos.
  • Filter by website. The website filter shows only captures from one site, which is often all you need to find something.
  • Sort by newest, oldest, name or size, and switch between a grid of thumbnails and a list.
  • Rename and tag. Open a capture’s menu and choose Details, rename & tags…. Give it a clear name and add tags separated by commas, such as design, bug-report. Tags are searchable.
  • Collections. Click New collection in the sidebar for a project, client or topic, then select captures and use Move to…. You can also pick a collection in the details dialog. Collections can be renamed or deleted later.
  • Favourites. Star the captures you reuse, such as a reference layout or a standard product shot, and find them in the Favorites view.
  • Details. The details dialog shows the source address, capture mode, size and pixel density, so you can always trace a screenshot back to its page.

Screenshots taken with other tools can join in: import images with the file picker, paste them, or drag them into the library, then tag and file them like the rest.

Find duplicates and compare versions

Repeated captures of the same page are the main source of clutter. FrameShot’s sidebar has a Duplicates view that lists screenshots that look the same, found by comparing the images themselves rather than their names. Keep the best one and delete the rest.

When two screenshots are almost the same, such as a page before and after a change, comparing is more useful than deleting. Select exactly two screenshots and click Compare to see them side by side, as an overlay, or as a difference image that highlights what changed. It’s a quick way to check a design fix or spot what moved between two versions of a page.

A simple weekly routine for screenshots

Ten minutes once a week keeps a screenshot collection under control. Put it in your calendar for Friday afternoon:

  1. Open the library and sort by newest to see the week’s captures.
  2. Delete the throwaways. Screenshots you took to paste into a chat once are done. Select them with Shift-click for a range, and press Delete. FrameShot asks you to confirm.
  3. Clear duplicates from the Duplicates view.
  4. Name and tag what you’ll keep. A clear name and one or two tags take seconds now and save minutes later.
  5. File them into the right collection, and star the ones you’ll reuse often.
  6. Archive finished projects. Select a collection’s captures and export them as a ZIP, or as one combined PDF for screenshots, and keep that file with the project’s other documents.
  7. Check storage. Sort by size to find the largest items, usually long recordings, and delete or download the ones you no longer need in the library.

The same habit works for your downloads folder: anything older than a month that you haven’t opened probably doesn’t need to stay.

Delete what you don’t need, back up what you do

The library is a working space, not an archive. It’s stored only in this browser on this computer: it isn’t synced to your other devices, and uninstalling FrameShot or using Settings → Storage → Clear all local data removes everything in it. So:

  • Download what you must keep and store it wherever you keep important files, with your normal backups.
  • Use ZIP exports for a batch. Recordings go into the ZIP as their video files.
  • Delete freely once a file is safely downloaded. Fewer captures make search faster and the useful ones easier to spot.
  • Watch the storage meter in the library, especially if you record video. Screenshots are small; long recordings are not.

Files you’ve already downloaded aren’t affected by anything you delete in the library.

Keep private screenshots private

Screenshots are often more sensitive than they look: a receipt shows your address, a bug report shows a customer’s email, a chat shows someone else’s messages. Organizing them is also a good moment to check them.

  • Redact before you share. Use a solid redaction box for passwords, tokens and card numbers. Blur and pixelation can sometimes be reversed for short text. Our redaction guide explains why.
  • Apply edits permanently for captures you keep. FrameShot normally keeps the original under your edits; Apply edits permanently replaces it, so the hidden parts no longer exist even in your library.
  • Know what syncs. FrameShot’s library stays on your computer, but folders you download into may be synced to a cloud drive by your system or another app. Keep sensitive downloads in a folder that isn’t.
  • Mind shared computers. Anyone who uses your Chrome profile can open the library. Delete sensitive captures when you’re done, or use a separate profile.
  • Give personal captures their own collection, such as receipts and documents, so you can review and delete them in one go, and so they don’t appear in front of colleagues if you open the library during a screen share.

Common questions

What is a good naming convention for screenshots?

Date first as YYYY-MM-DD, then the site or project, then two or three words about the content, joined with hyphens: 2026-11-16-example.com-pricing-page. A file name template can fill in the date and site for you.

How do I find an old screenshot quickly?

Search by the website or page title if you remember them, or filter by website and sort by date. In FrameShot, press / and type part of the name, title, address or a tag.

How do I delete duplicate screenshots?

Open the Duplicates view in FrameShot’s library, which lists visually identical screenshots, keep the best copy and delete the rest. For files on disk, sorting by date and size helps spot repeats.

Are screenshots in the FrameShot library backed up?

No. They are stored only in this browser on this computer and aren’t synced. Download or export anything you want to keep long term.

Can I organize screenshots taken with other tools?

Yes. Import them into the library with the file picker, by pasting, or by dragging them in. Want them to look better before you file them? See how to make screenshots look professional, and for menus that need a timer, how to take a delayed screenshot.
