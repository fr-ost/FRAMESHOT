# Data usage (Privacy practices tab)

**What user data do you plan to collect from users now or in the future?** Tick **none** of the boxes:

| Category | Collected? |
|---|---|
| Personally identifiable information | No |
| Health information | No |
| Financial and payment information | No |
| Authentication information | No |
| Personal communications | No |
| Location | No |
| Web history | No |
| User activity | No |
| Website content | No |

Screenshots, recordings (including microphone sound and camera images the user chose to include) and the title and address of captured pages are stored **only on the user's device**, in the user's own library. They are never sent to the developer or anyone else, so under the store's definitions nothing is "collected". FrameShot has no analytics, telemetry, ads or accounts. The optional Support page only shows donation addresses; FrameShot never sees or processes donations.

**Certifications** (tick all three):

- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

**Privacy policy URL:** host `privacy-policy.html` (in this kit) at a public address, for example `https://www.shahriarahmed.net/frameshot/privacy`, and paste that URL.
